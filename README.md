# To Do
تطبيق ويب (PWA) لمتابعة المهام والجدول اليومي. بيشتغل أوفلاين وبيتحفظ على الجهاز.

## النشر على GitHub Pages
1. ارفع كل الملفات في root الريبو (وفيها `index.html`).
2. Settings ← Pages ← Branch: `main` / root.

## صفحة التحميل المباشر
الرابط: `https://USERNAME.github.io/REPO/download.html`
- مفيش أي لينك ليها جوه التطبيق، وعليها `noindex` + `robots.txt` فمش بتظهر في جوجل. بتتفتح بس لمن يعرف الرابط.
- مفتاح الإيميل (Web3Forms) موجود في `config.js`.
